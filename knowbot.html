// 01 · THE PROBLEM

Tribal knowledge is a liability.

In most Indian IT SMEs, critical knowledge lives in one senior engineer's head. When they quit — and they always quit — that knowledge walks out with them. No documentation, no handover, no system. Just a new hire asking the same questions for the next six months.

KnowBot was built for SDG 8: Decent Work and Economic Growth. The thesis: give small teams an enterprise-grade knowledge management system that actually works in Indian languages, on Indian internet, for Indian company budgets.

₹0 / month infra cost on free tier
< 1.2s average RAG response time
Hindi + English language support via Sarvam AI

// 03 · WHAT ACTUALLY WENT WRONG

The problems nobody writes tutorials about.

AUDIO PIPELINE

Sarvam AI's 30-second limit

Sarvam's STT API hard-caps audio at 30 seconds. Long voice queries got silently truncated. Fixed by chunking WAV audio at 28-second intervals via pydub and stitching transcripts on the backend.

VECTOR DB

Qdrant payload index requirements

Qdrant throws silent failures if you filter on a field without a payload index. Spent hours debugging empty results before finding the missing create_payload_index() call in the docs footnotes.

AUDIO FORMAT

WebM vs WAV sample rate mismatch

Browser MediaRecorder outputs WebM at 48kHz. Sarvam expects 16kHz WAV. Every transcript came back as noise until pydub resampling was added to the ingestion pipeline.

// 04 · GOOGLE SOLUTION CHALLENGE 2026

Built under SDG 8.

KnowBot was submitted to Google Solution Challenge 2026 — a global competition for student developers building on Google technology to address the UN Sustainable Development Goals. KnowBot targeted SDG 8: Decent Work and Economic Growth, with the argument that knowledge retention directly impacts productivity and job quality in growing economies.

Stack alignment with Google: Gemini 2.0 Flash as the LLM backbone, deployed on GCP-adjacent infrastructure.

"The hardest part wasn't the RAG pipeline — it was getting Sarvam AI's STT to handle Gujarati-accented Hindi without hallucinating entire sentences."
// 05 · RETROSPECTIVE

If I built this again.

  • →
    Start with Qdrant local Docker from day one. Free-tier cloud clusters get deleted after inactivity and you lose all your vectors.
  • →
    Abstract the STT provider behind an interface. Sarvam works for Hindi but swapping it out later meant touching too many layers.
  • →
    Add document re-ingestion as a scheduled job, not a manual CLI command. Users don't run CLI commands.
